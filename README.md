# E-Com Wallet prototype

Interactive prototype based on the selected E-Com Wallet Figma exploration.

Open `index.html` in a browser, or serve this directory with a static HTTP server. No build step or dependencies are required.

The prototype includes simulated checkout, draggable payment cards, purchase details, receipt sharing, spending and savings views. Payments, exports and sharing are simulated; no real transactions or messages are sent.

## Files

- `index.html`: screen layouts and base styles
- `app.js`: navigation and prototype interactions
- `motion.js` and `motion.css`: animations and card carousel
- `assets/`: local design images and SVGs

## GitHub Pages

Publish the root directory of the `main` branch. `.nojekyll` keeps the site as plain static files.
